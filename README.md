The needed packages for the program should be able to be installed using the commands from the **requirements.txt**, furthermore having **notepad++** enhances the experience. Since windows's notepad cannot move the cursor, when clicking on node in the roadmap graph, it only opens the .json file instead of opening it and moving the cursor to the clicked ID.

**Double-clicking** a node opens its location in the designated .json file which contains a more detailed description of that item.
